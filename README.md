# Django Full App

Full Django 5.1 blog application with authentication, Jinja2 templates, static files, DRF API, custom admin actions, and class-based views.

**Stack:** Django | **Complexity:** complex
**Tags:** `django`, `fullstack`, `blog`, `auth`, `drf`, `templates`, `python`

## Quick Start

```bash
pip install -r requirements.txt
python manage.py runserver
```

## Docker

```bash
docker compose up --build
```
